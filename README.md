# Pit Wall

A simulated Formula 1 live tracker for the 2026 Singapore Grand Prix, with a 2026 calendar and championship standings.

Everything lives in a single file, `index.html`, with no build step. Open it in a browser, or host it on GitHub Pages.

## Features

- **Live tracker:** an animated Marina Bay track map and a timing tower, with play/pause, 1×–60× speed, restart, a safety car, pit stops, fastest laps and a race control feed.
- **Follow a driver:** click a car on the map or a row in the tower, or use ↑/↓. Space plays or pauses and R restarts.
- **Calendar & standings:** a live countdown to the race, a filterable 24-round calendar, and driver and constructor standings with search.

Race positions and championship points are simulated sample data.
